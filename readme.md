# Currency Converter

## Project Overview

The **Currency Converter** is a web-based application developed using HTML, CSS, and JavaScript. It allows users to convert an amount from one currency to another by selecting the required currencies and entering an amount.

The application provides a simple and interactive interface to perform currency conversions and understand the value of different currencies.

## Technologies Used

- **HTML5** – Used to create the structure of the currency converter, including input fields and selection options.
- **CSS3** – Used to design and style the application with a clean and user-friendly interface.
- **JavaScript** – Used to handle user input, conversion calculations, and dynamic result display.

## Project Structure

```text
Currency-Converter/
│
├── index.html
├── style.css
└── script.js
```

## Features

- Enter the amount to be converted.
- Select the source currency.
- Select the target currency.
- Convert the entered amount into the selected currency.
- Display the converted amount clearly.
- Perform currency conversion based on the implemented conversion rates or exchange-rate data.
- Provide an interactive and easy-to-use interface.
- Allow users to perform multiple conversions by changing the amount or currency selections.

## How the Application Works

1. The user opens the Currency Converter application.
2. The user enters the amount in the input field.
3. The user selects the currency to convert from.
4. The user selects the currency to convert to.
5. JavaScript retrieves the entered amount and selected currencies.
6. The application processes the conversion using the implemented exchange-rate logic.
7. The converted amount is displayed on the webpage.

## File Description

### 1. index.html
- Creates the basic structure of the Currency Converter.
- Provides input fields for entering the amount.
- Includes currency selection options.
- Contains the conversion button and result display area.
- Connects the CSS and JavaScript files.

### 2. style.css
- Defines the visual appearance of the application.
- Styles input fields, dropdowns, buttons, and result sections.
- Maintains proper spacing and alignment.
- Improves the overall user experience.

### 3. script.js
- Retrieves the amount entered by the user.
- Gets the selected source and target currencies.
- Performs the currency conversion.
- Handles button click events.
- Displays the converted result dynamically.
